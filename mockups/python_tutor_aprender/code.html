Hoy vamos a aprender los bucles for.

Un bucle for nos permite repetir un bloque de código varias veces.

Por ejemplo, si queremos mostrar los números del 1 al 5, podemos escribir:

for i in range(1, 6):
print(i)

¿Te gustaría intentar modificar el código para que muestre solo los números pares?

Creo que sería usando un if dentro del bucle
¡Exacto! Esa es una buena idea. Inténtalo y si necesitas una pista, avísame.
main.py
1 2 3 4 5
# Muestra los números pares del 1 al 10
for i in range(1, 11):
if i % 2 == 0:
print(i)
